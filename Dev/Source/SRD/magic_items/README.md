# Oggetti magici

Ogni file Markdown rappresenta una singola entita del dataset SRD 5.2.1.

## Frontmatter

Il frontmatter YAML contiene solo metadati strutturati utili per ricerca, filtri e collegamenti: identificatore, nome e campi tassonomici o meccanici principali. I campi vuoti o derivabili dal testo non devono essere aggiunti.

## Corpo nota

Il corpo della nota contiene il testo leggibile dell'entita: descrizione, sottosezioni, tabelle e blocchi regola. Non duplicare nel corpo i campi gia presenti nel frontmatter, salvo quando fanno parte naturale del testo della regola.
